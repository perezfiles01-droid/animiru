# Animiru extensions

Everything in this folder is one extension repository. Paste one URL into an
app and it lists every extension here — and keeps listing them as more are
added, because the index rebuilds itself on every push.

## The repository URLs

Two addresses, the same file. Either works in either app; each is named the
way that app's users expect.

**Animiru** — Settings → Extension → paste:

```
https://raw.githubusercontent.com/perezfiles01-droid/animiru/main/extensions/index.json
```

**Mangayomi** — Settings → Browse → Extension repos → **Anime** → paste:

```
https://raw.githubusercontent.com/perezfiles01-droid/animiru/main/anime_index.json
```

Both are generated by `scripts/generate-extension-index.js` from the sources
themselves and are byte-identical, so neither can list something the other
does not. A check fails if they ever differ.

This page used to say one link worked in both apps. It did not. The index
omitted `sourceCodeLanguage`, and Mangayomi reads that field as
`SourceCodeLanguage.values[json['sourceCodeLanguage'] ?? 0]` against
`enum { dart, javascript, mihon, lnreader }` — so leaving it out did not
fail loudly, it declared these JavaScript sources to be Dart. Every entry now
carries it, along with the six other fields Mangayomi reads.

## Adding an extension

Put a `.js` file in [`sources/`](sources). That is the whole job.

On push, CI reads the `mangayomiSources` header out of your file, rewrites
`index.json`, and updates the table at the bottom of this page. The URL above
does not change, and the new extension appears the next time an app refreshes
the repository.

`index.json` is generated — **do not edit it by hand**, the next push will
overwrite the change. See [ADDING-AN-EXTENSION.md](../ADDING-AN-EXTENSION.md)
for the header fields and the one rule that catches people out (bump the
version when you change a source, or the app keeps serving the old code).

To try it before pushing:

```
node scripts/generate-extension-index.js
node scripts/generate-extension-readme.js
```

## What a source is

One JavaScript file: a declaration of what it is, and a class the app calls.

```js
const mangayomiSources = [{
  name: "My Source",
  id: 1002,                        // unique across this folder
  lang: "en",
  baseUrl: "https://example.com",
  iconUrl: "https://example.com/favicon.ico",
  version: "1.0.0",
  itemType: 1                      // 0 manga, 1 anime, 2 novel
}];

class DefaultExtension extends MProvider {
  async getPopular(page) { /* ... */ }
  async search(query, page, filters) { /* ... */ }
  async getDetail(url) { /* ... */ }
  async getVideoList(url) { /* ... */ }
}
```

Sources run in a sandbox that is neither a browser nor Node: there is no
`fetch`, no `require`, no `window`, and `eval` is disabled deliberately. HTTP
is `new Client()`, settings are `new SharedPreferences()`. A source written
for Mangayomi runs here unmodified.
